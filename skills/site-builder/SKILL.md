# Site Builder

Корень проекта — на два уровня выше этой папки. Этот skill содержит инструкции разработки проекта; отдельная глобальная установка не нужна.

## Вход в задачу
1. Прочитай текущий этап/журнал и протокол контрольных точек в [STAGES.md](../../docs/STAGES.md).
2. Проверь, не ожидает ли предыдущая контрольная точка подтверждения. Если ожидает — выполняй только запрошенные исправления либо принимай явное подтверждение; не начинай следующую пару сам.
3. Для контента, цен, контактов и медиа прочитай нужные разделы [PROJECT.md](../../docs/PROJECT.md); для UI, эффектов, SEO/performance — [DESIGN.md](../../docs/DESIGN.md).
4. Установи минимальный набор изменяемых файлов. Чужие изменения сохраняй. Недостающий факт не заменяй предположением: записывай вопрос и выполняй независимую часть.

## Экономная реализация
- Работай по одному этапу. Несколько запрошенных этапов выполняй последовательно только до ближайшей обязательной остановки.
- Ищи адресно через rg; не читай весь репозиторий, lockfile и большие сборки без причины. Повторно открывай только изменившиеся или непонятные файлы.
- Используй существующие компоненты и зависимости. Для простого эффекта достаточно CSS. Не делай универсальную платформу, админку, CRM и абстракции «на будущее».
- Сначала небольшой связный план, затем реализация и проверка. Не переписывай рабочие секции ради личного предпочтения.
- Документацию библиотек проверяй адресно при внедрении конкретного компонента; не исследуй все каталоги заранее.
- Проверяй изменённое поведение; после существенных изменений выполняй требуемые build/lint/typecheck. Полный итоговый аудит — этап 11. Не ослабляй проверки ради экономии.

## Завершение
Обнови статус и фактические проверки в STAGES.md. Не называй этап готовым при невыполненном критерии. После чётного этапа выполни протокол скриншотов из STAGES.md: реальный desktop и при готовом mobile — mobile, `artifacts/progress`, показ пользователю, статус ожидания, остановка до подтверждения. Нельзя обойти эту точку запуском фоновой работы.

Отчёт короткий: что изменилось, какие файлы затронуты, что проверено, блокеры. На контрольной точке дополнительно — 1–2 снимка и запрос подтверждения. Не пересказывай код и все инструкции. После перезапуска продолжай по журналу, не повторяй уже завершённую работу.
